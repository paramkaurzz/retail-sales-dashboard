 Retail Sales Dashboard

Interactive Power BI dashboard analyzing 1,010 retail transactions to identify revenue trends, product performance, store performance, and key business metrics.

Key Metrics

* Total Revenue: $1.06M
* Average Transaction Value: $1.05K
* Total Units Sold: 3,048

Analysis

The dashboard provides interactive analysis of:

* Revenue by product
* Revenue by store
* Revenue trends over time
* Revenue by category
* Interactive filtering by store and product

 Tools

* Power BI
* SQL
* Excel

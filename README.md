 Retail Sales & Business Performance Dashboard

A data analytics project using Excel, SQL, and Power BI to analyze retail sales performance and identify business trends and key performance indicators.

 Project Overview

This project analyzes 1,010 retail transactions across multiple stores, products, and categories.

The analysis focuses on:

* Revenue performance
* Product performance
* Store performance
* Sales trends over time
* Transaction metrics
* Data quality

 Dashboard

The interactive Power BI dashboard provides:

* Total Revenue
* Average Transaction Value
* Total Units Sold
* Revenue by Product
* Revenue by Store
* Revenue Trends
* Revenue by Category
* Interactive Store and Product filters

 Tools & Technologies

* Power BI — Interactive dashboard and visualization
* SQL — Data analysis and aggregation
* Excel — Data preparation and validation

 Key Results

* 1,010 transactions analyzed
* $1.06M total revenue
* $1.05K average transaction value
* 3,048 total units sold
